Este archivo es un ejemplo. Tiene `borrador: true`, así que **solo se ve mientras trabajas** (`pnpm dev`) y no se publica.

## Cómo escribir un artículo

1. Copia este archivo dentro de `src/content/articulos/` y cámbiale el nombre. El nombre será la dirección: `mi-articulo.md` → `/articulos/mi-articulo`.
2. Llena los datos de arriba: título, descripción, fecha y tema.
3. Escribe el texto debajo.
4. Cuando esté listo, cambia `borrador: true` por `borrador: false`.

## Qué puedes usar

- Listas como esta.
- **Negrita** y [enlaces](/).
- Subtítulos con `##`.

Mientras no haya artículos publicados, la sección de artículos del inicio no aparece.
